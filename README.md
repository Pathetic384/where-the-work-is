# Where The Work Is

An interactive data documentary about the Australian job market, built from ABS 8155.0 Australian Industry (19 years to 2024-25).

Live at **https://pathetic384.github.io/where-the-work-is/**

Built by the Data Driven Storytelling Studio, UTS. Static HTML/CSS/JS, no build step, no runtime dependencies, no network calls after the initial page load.
